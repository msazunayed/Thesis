# GlaucomaNet 👁️

A CNN-based glaucoma detection system for retinal fundus images, built on the
**Hillel Yaffe Glaucoma Dataset (HYGD)** — 747 annotated fundus images
classified as GON+ (glaucomatous) or GON− (non-glaucomatous).

> **Research tool only.** Not a medical device. Always consult a qualified
> ophthalmologist for clinical diagnosis.

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Prepare the dataset

Unzip the HYGD dataset into `data/` so the layout is:
```
data/
  Images/   (747 .jpg files)
  Labels.csv
```

### 3. Train the model

```bash
python model/train.py
```

Flags (all optional):
| Flag           | Default           | Description                          |
|----------------|-------------------|--------------------------------------|
| `--epochs`     | 30                | Training epochs                      |
| `--lr`         | 3e-4              | Learning rate (AdamW)                |
| `--batch`      | 32                | Batch size                           |
| `--img_size`   | 128               | Resize images to N×N                 |
| `--images_dir` | data/Images       | Path to fundus images                |
| `--labels_csv` | data/Labels.csv   | Path to Labels.csv                   |

The script performs a **patient-level** 70 / 15 / 15 split (no data leakage),
uses **weighted sampling** and **weighted loss** to handle the class imbalance
(548 GON+ vs 199 GON−), and saves the best checkpoint by validation accuracy.

### 4. Evaluate on the test set

```bash
python model/test.py
```

Prints accuracy, per-class accuracy, confusion matrix, sensitivity,
specificity, and AUC (no sklearn required).

### 5. Run the web app

```bash
uvicorn main:app --reload
```

Open `http://localhost:8000` and upload a fundus image to get a prediction.

## Model Architecture — GlaucomaCNN

```
Input  (3 × 128 × 128)
  ↓  Conv 3→32  + BN + ReLU + MaxPool   → 64×64
  ↓  Conv 32→64 + BN + ReLU + MaxPool   → 32×32
  ↓  Conv 64→128+ BN + ReLU + MaxPool   → 16×16
  ↓  Conv 128→256+BN + ReLU + AvgPool   →  4×4
  ↓  Flatten → Linear(4096→512) → Dropout(0.5) → Linear(512→2)
Output logits  (batch × 2)
```

**Design choices:**
- 4 convolutional blocks (vs 3 in JaalTaka) — fundus images are more complex than banknotes.
- 128×128 input — balances detail retention with memory cost.
- ImageNet normalization statistics — better than [0.5, 0.5, 0.5] for natural images.
- Weighted random sampler + weighted loss — handles 2.75× class imbalance.
- Aggressive augmentation (flips, rotation, color jitter, affine) — compensates for the small dataset size (747 images).
- AdamW optimizer with cosine LR schedule — more stable than vanilla Adam.

## Dataset

**Hillel Yaffe Glaucoma Dataset (HYGD)** — v1.1.0  
747 deep fundus images (DFIs) from Hillel Yaffe Medical Center, annotated
for glaucomatous optic neuropathy.

- GON+ (glaucomatous): 548 images
- GON− (non-glaucomatous): 199 images

If you use this dataset please cite:

> Abramovich O, et al. (2025). Hillel Yaffe Glaucoma Dataset (HYGD).
